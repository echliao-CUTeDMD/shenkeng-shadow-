# 深坑尋寶：老街暗影

繁體中文 HTML 桌遊，使用提供的水彩卡圖與《深坑尋寶：老街暗影》完整規則書 v1.1，參考《矮人礦坑》基本版。**3–10 人共用同一台電腦、平板或手機，輪流接手。**

## 直接遊玩

開啟 `index.html` 即可。程式、樣式與水彩圖片全部內嵌；不需安裝、登入或連網，也不需要伺服器。此版本沒有 AI 或遠端多人連線。

1. 選擇玩家人數，最年輕玩家坐 1 號，座位依順時針排序。
2. 玩家接手裝置，其他人移開視線，再按「已接手」。
3. 選手牌。道路可轉 180°，點綠框放置；行動依提示選玩家、裝備或目標。也可蓋牌棄置。
4. 系統補牌並遮蔽資訊，再交給下一位。街坊線索需看完後按「收好地圖」。
5. 接通文化箱立即結算；全部手牌用完仍未接通，暗影隊勝。完成三回合後比較個人總分。

手機上先選手牌，再往下捲到棋盤點落點。棋盤的 ＋／− 可調整大小，「全景」縮放至目前版面；放大後可以左右與上下滑動。

## 上傳 GitHub Pages

**最簡單只需上傳 `index.html`；不要直接上傳 ZIP 當作網站。**

1. 在 GitHub 建立 repository，例如 `shenkeng-shadow`。
2. 選 **Add file → Upload files**，把 `index.html` 放在 repository 根目錄，提交到 `main`。
3. 開啟 **Settings → Pages**。
4. 在 **Build and deployment → Source** 選 **Deploy from a branch**。
5. 選 **main** 與 **/(root)**，按 **Save**。
6. 等待部署完成，使用 Pages 頁面顯示的網址分享。通常為 `https://你的帳號.github.io/shenkeng-shadow/`。

也可上傳整個解壓縮後的專案內容，以保留可編輯原始碼；確認根目錄有 index.html，不要額外包一層資料夾。未替你建立或發布遠端 repository。

[GitHub 官方部署說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 規則依據與原型差異

玩法以使用者原型規則書為優先；不把原型當作官方《矮人礦坑》的逐張複製。

| 項目 | 本網頁版本 |
|---|---|
| 道路 | P01–P40，32 張連通道路、8 張單入口封閉巷 |
| 道路分布 | 老街直巷 7、河岸步道 7、豆腐轉角 5、茶香轉角 5、廟埕岔路 3、竹筍岔路 3、四寶交會 2、四方向封閉巷各 2 |
| 行動 | 9 故障、6 單一修復、3 二擇一修復、3 工區拆除、6 街坊線索 |
| 裝備故障 | 可對任意玩家，包括自己；同種故障不可疊加 |
| 目標 | 四寶文化箱、集順廟前廣場、老街茶香巷；皆為四向通路，位置隨機 |
| 身分 | 依 3–10 人配置，多留一張未發；每回合重抽，結算公開未發身分 |
| 文化點 | 1 點 ×16、2 點 ×8、3 點 ×4；每回合完整重洗 |
| 導覽隊得分 | 每人一張文化點；由完成者逆時針秘密挑選，跳過暗影 |
| 暗影完成道路 | 導覽隊勝；從完成者右側第一位導覽開始選點 |
| 暗影得分 | 實際 1／2–3／4 人，各得 4／3／2 點；直接記分、不抽文化點卡 |
| 全場勝利 | 三回合個人總分最高者勝，同分共享勝利 |

蓋牌目標忽略邊緣匹配；連通開口抵達才揭開。翻開後原有路牆衝突保留，但不通行；新放牌仍須匹配每一條已知相鄰邊。工區拆除後孤立道路留在原位，不能當作新路唯一連通來源。牌庫空時不重洗棄牌；所有手牌用完才結束。

程式補充：換手遮罩、合法落點、自動補牌、每人秘密線索筆記、三回合分數記錄、圖鑑和本機自動存檔。這些只輔助操作，沒有新增卡牌能力。

## 存檔與同機秘密資訊

進度存於目前瀏覽器的 localStorage，重整後需重新接手。換網址、換瀏覽器、清除網站資料或無痕模式不保證保留。畫面會提示儲存失敗。開新遊戲會取代現有存檔。

換手遮罩適合同機桌遊；秘密資料存在玩家裝置，可被瀏覽器開發工具讀取，並非防作弊網路系統。網站沒有分析追蹤、帳號或對外傳送遊戲資料。

## 原始碼與驗證

- `index.html`：可獨立使用的遊戲，發布只需此檔。
- `src/engine.js`：規則、回合、牌庫及計分。
- `src/ui.js`、`src/style.css`、`src/template.html`：介面與樣式。
- `assets/`：從提供的卡牌 PDF 擷取的卡面、卡背及版圖裝飾。
- `build.cjs`：以 Node.js 將圖片與程式打包為單一 HTML，無建置依賴。
- `src/engine.test.cjs`：規則與三回合測試。
- `tests/browser.cjs`：Playwright 介面測試。
- `preview-desktop.png`、`preview-mobile.png`：測試場景預覽；不會改變新局設定。

修改後執行：

```sh
node build.cjs
node src/engine.test.cjs
```

瀏覽器測試需另備 Playwright 與瀏覽器：

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser.cjs
```

也可用 `CHROME_PATH` 環境變數指定 Chromium 系列瀏覽器執行檔。

已驗證：3–10 人配置、67 張牌數守恆、全員棄牌和實際合法出牌三回合、單入口封巷、旋轉、孤立區、相鄰匹配、自我故障、修復、拆路、秘密線索、四向空點、同次多目標揭露、逆時針計分、暗影固定獎分、文化點重新洗牌、下一回合先手；桌機／390px 手機操作、秘密資訊換手、重新載入存檔、圖片載入及零 JavaScript 錯誤。
